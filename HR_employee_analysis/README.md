## HR Employee Turnover Analysis

**Description**
This project focuses on analyzing employee turnover trends and identifying possible factors affecting employee retention, satisfaction, workload, and overall performance. The goal of the project is to generate business insights that may help improve employee engagement and reduce turnover. The analysis was done using Python and focused on exploring patterns related to employee satisfaction, working hours, project workload, salary levels, promotions, and years spent in the company.

**Tools:** Python, pandas, matplotlib, seaborn, and Google Colab

**Skills:** Data Cleaning, Exploratory Data Analysis (EDA), Data Visualization, Business Insight Generation, Employee / HR Analytics, and Reporting and Interpretation.

**Analysis Performed:** Employee turnover analysis, satisfaction level analysis, work hours analysis, project workload analysis, salary level analysis, promotion analysis, and correlation analysis using heatmaps.

**Files Included:** Python Notebook (.ipynb), HR Dataset (.csv), and Project Documentation.

## Dataset
* HR_comma_sep.csv - Employee HR dataset used for employee turnover and workforce analysis.
  * Fields: 10
  * Rows: 14,999
