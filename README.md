## Customer Support KPI Dashboard

**Description:** This project focused on analyzing a customer support dataset using Excel and Power BI. The dataset included customer call records, support topics, agent performance, satisfaction ratings, response times, and resolution status. The goal of the project is to analyze customer support operations and identify trends in call handling performance, customer satisfaction, and operational efficiency. The project involved data cleaning, KPI creation, pivot table analysis, DAX measures, dashboard development, and business insight generation.

**Tools:** Excel, Power BI, Pivot Tables, and DAX.

**Skills:** data cleaning, KPI analysis, dashboard design, data visualization, business analysis, customer operations analysis, DAX, and reporting.

**Files Included:** Cleaned Excel dataset, Power BI dashboard (.pbix), Dashboard screenshots, and Project documentation

**Dataset**
* Call-Center-Dataset.csv - Call center operational data used for performance, efficiency, and customer satisfaction analysis.
  * Fields: 10
  * Rows: 5,000

## HR Employee Turnover Analysis

**Description**
This project focuses on analyzing employee turnover trends and identifying possible factors affecting employee retention, satisfaction, workload, and overall performance. The goal of the project is to generate business insights that may help improve employee engagement and reduce turnover. The analysis was done using Python and focused on exploring patterns related to employee satisfaction, working hours, project workload, salary levels, promotions, and years spent in the company.

**Tools:** Python, pandas, matplotlib, seaborn, and Google Colab

**Skills:** Data Cleaning, Exploratory Data Analysis (EDA), Data Visualization, Business Insight Generation, Employee / HR Analytics, and Reporting and Interpretation.

**Analysis Performed:** Employee turnover analysis, satisfaction level analysis, work hours analysis, project workload analysis, salary level analysis, promotion analysis, and correlation analysis using heatmaps.

**Files Included:** Python Notebook (.ipynb), HR Dataset (.csv), Data Visualizations / Charts, and Project Documentation.

**Dataset**
* HR_comma_sep.csv - Employee HR dataset used for employee turnover and workforce analysis.
  * Fields: 10
  * Rows: 14,999

**Acknowledgements**
This dataset was sourced from **Kaggle**.

**Source Link:** https://www.kaggle.com/code/jacksonchou/hr-analytics/script
